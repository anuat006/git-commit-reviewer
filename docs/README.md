# docs

| Item | What it is |
|---|---|
| `Security Commit Reviewer - Solution Design.docx` | The solution design document: architecture, control flow, components, safety design, configuration, issue format, status and limits |
| `architecture.svg`, `architecture.png` | The architecture diagram on its own (also embedded in the document) |
| `evidences/` | Console output, audit trails and the created issue for the three demo runs; see `evidences/README.md` |
| `_to_delete/` | A half-built demo repo from an abandoned attempt. Safe to delete this whole folder |

The demo repo itself is not part of the project. Build it with `python scripts/make_demo_repo.py --dest <folder>`.
